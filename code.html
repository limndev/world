이 코드로 바꾸는 순서

  1. 코드 파일 내려받기를 눌러 두세요. 코드를 잊어버렸을 때 다시 볼 곳은 이 파일뿐이에요(서버에는 암호화된 값만 남아요).
  2. SQL 복사하기를 누르고, Supabase 대시보드의 SQL Editor에 붙여넣어 Run을 눌러요.
  3. SQL 끝에 확인용 한 줄이 붙어 있어요. 결과 칸에 code_ok 가 true 로 나오면 바뀐 거예요. (false 이면 바뀌지 않은 거니 다시 실행해 보세요.)
  4. 학생들에게 코드를 알려 줘요. 이미 들어온 학생은 그대로 있고, 새로 들어올 때부터 새 코드가 필요해요.
SQL 미리 보기 (무슨 뜻인지 읽어 보세요) 

          
① crypt(코드, gen_salt('bf')) 는 코드를 되돌릴 수 없는 암호화 값(해시)으로 바꿔요. 서버는 코드 자체를 저장하지 않고 이 값만 저장해요. ② where world_id = ... 는 이 학급 한 줄만 바꾸라는 조건이에요. 조건이 없으면 모든 줄이 바뀌므로 지우지 마세요.
